## 🔥 Featured Projects

### 🤖 Multimodal Telegram AI Assistant
Built and deployed a fully local, multimodal chatbot with text, image captioning, image transformation, and text-to-image generation using **LLaMA (Ollama)**, **Gemma**, and **ComfyUI Flux**. Orchestrated with **n8n** and **PostgreSQL** for persistent memory.
- ✨ Zero external APIs - complete privacy
- 🎨 Multimodal AI capabilities
- 💾 Persistent conversational context

### 🗣️ Language Identification System
Developed a language identification system that accurately identifies **7 languages** (Arabic, Portuguese, English, Italian, Spanish, French, German) in audio files using **Python** and **Flask**.
- 📱 Available as mobile and web application
- ⚡ Real-time processing

### 💰 Cryptocurrency Price Prediction
Built a system using **NLP** and **sentiment analysis** of tweets to predict cryptocurrency prices.
- 📊 Real-time sentiment analysis
- 🤖 Machine learning price predictions

### 📹 YouTube & TikTok Web Scraper
High-performance media scraper capable of downloading **100+ videos** with a single click, with automatic trimming capabilities.
- ⚡ Batch processing
- ✂️ Automated video trimming
